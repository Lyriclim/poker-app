# 🃏 The ace in the pack · 德州扑克

一个**朋友之间**玩的在线德州扑克网站。**学习项目**：不盈利、不涉及真钱，只使用虚拟筹码。

## 本地优化版（2026-09-28）

- 玩家可在大厅和牌桌切换 English / 简体中文，选择保存在浏览器；中文提示按牌桌语境写，不逐字硬译。PC 格局保留，独立 iPhone 竖屏牌桌采用同一套深色风格，放大手牌和公共牌并醒目标出当前行动者。
- ¼ / ½ / ¾ / Pot / +15 快捷下注放在同一排；修复已有本轮下注时的比例加注总额。整数滑块和金额输入保留。
- All-in 和下注全部筹码前显示 Take a breath. 确认弹窗；不增加行动倒计时，保留原有挂机检测。
- Classic 输光并结算后可原座位 Rebuy，自选整数筹码，不需要房主批准。Tournament 统一起始筹码，不允许开赛后加入或重新买入。
- 输入名字即可进入，无密码、注册步骤或邀请码；下次用同名可回到已有座位。名字就是身份，因此知道该名字的人也能进入对应账号。
- 创建 Classic 固定/自动涨盲牌桌或 Tournament。服务器掌管盲注时间，下一手应用新盲注。提供可编辑盲注表、级别时长、比赛开赛、淘汰排名与冠军结算。
- Session 展示本场带入、补码、带出、当前筹码与净输赢；房主可以暂停下一手、恢复、结束本场及清理离线座位。已开始的比赛不能移除仍有筹码的参赛者。
- Classic 房主可在 Session 中选择 Last hand：正在进行的一手作为最后一手，否则再打下一手。结算后自动结束本场，结算前可 Cancel last hand；Tournament 仍按淘汰规则结束。
- 本场结束后显示 Session Highlights：Pot Collector（至少赢 2 手）、Showdown Regular（至少参与 3 次多人摊牌）、Comeback Kid（曾净亏损、最终净盈利）、Biggest Catch（单手净赢最多）。并列共享称号，只统计升级后已结算的手牌，补码不算盈利，不增加长期排名。
- Chips / BB 显示切换，主池/边池与逐池赢家结算展示。手机回到前台时重新同步牌桌。
- 中途入座下一手参与；房主可扩座，缩座仅限两手之间且不移除已占座位。
- 首手仍需准备；之后取消摊牌 Skip 和单独的每手 Ready 步骤，玩家在结算弹窗点「下一手」即确认继续。Classic 玩家输光后可在结算弹窗直接「补码并加入下一手」，补码成功等同确认继续；不继续则离座。在线的零筹码座位作出选择前不会抢先发下一手，掉线座位不阻挡发牌。断线重连会重放尚未确认的结算，已确认继续的状态在短暂断线后保留。
- 结算、座位余额、比赛状态与本场流水通过数据库事务保存；保存失败可重试。并发入座与结算不会覆盖新筹码。
- 本场记录保存在本机；没有长期钱包、群组或个人战绩系统。新版开始的一手会在发牌和每次行动后把牌堆、底牌、下注及轮次安全地保存到服务器本机；服务意外重启后冻结该手，至少两位玩家回来后由房主恢复。升级前已开始、没有保存快照的手牌仍只能从上一手结算恢复。
- 此次升级前的数据库备份位置记录在 .runtime/latest-db-backup.txt。旧牌桌从升级时的座位余额开始计算本场流水，不能补出过去未记录的买入明细。

## 功能

- 玩家入口：只填名字，首次自动创建玩家；同名复用原身份；JWT 在浏览器中保留 30 天
- 大厅：创建 Classic / Tournament 牌桌，设置盲注与人数 2–9；从列表直接进入
- 入座**自由带入虚拟筹码**（无跨桌账户余额，本场记录保留带入和带出），可围观聊天（未入座为观众）
- 准备机制：首手所有玩家准备后开局；以后确认结算即加入下一手
- 标准德州扑克规则（详见下文「游戏规则」）：盲注、按钮轮转、下注/加注/全下、边池、烧牌、摊牌比牌
- 服务器权威 + 信息隔离：客户端永远看不到别人的底牌
- 原有**挂机检测**：60 秒未行动弹窗提醒，再 20 秒无回应则自动过牌/弃牌
- 断线保留座位、标记离线，重连继续
- 摊牌交互：多人摊牌各自确认；全弃牌时赢家可选**亮牌 / 盖牌（muck）**
- 聊天：支持牌桌上的气泡（观众无座位）
- 每局结果与每个动作落库（`Hand` / `HandAction`）

## 快速开始

要求：**Node.js ≥ 20**（开发环境为 v24）。

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量（先复制模板）
cp apps/server/.env.example apps/server/.env

# 3. 初始化数据库（生成 Prisma Client + 建表）
npm run db:push

# 4. 启动（同时起后端 3001 端口 + 前端 5173 端口）
npm run dev
```

打开 http://localhost:5173 ，输入名字、创建牌桌，朋友也输入名字后从大厅选择同一牌桌即可一起玩。

## 生产部署

后端会同时托管打包好的前端（同源，前端用相对路径，无需单独配域名）：

```bash
npm run build
npm run start -w @poker/server
```

启动后访问 `http://localhost:3001` 即可。双击 Start Public Access.cmd 开启免费的临时公网链接，Stop Public Access.cmd 停止分享；若旧版服务仍在运行，结束牌局后双击 Update App.cmd 更新。电脑需要保持开机联网，重启隧道会更换链接。详见 PUBLIC-ACCESS.md。

## 环境变量

在 `apps/server/.env` 中配置（模板见 `.env.example`）：

| 变量 | 默认值 | 说明 |
|---|---|---|
| `DATABASE_URL` | `file:./dev.db` | SQLite 文件路径；换 Postgres 时改成连接串并改 schema 的 provider |
| `JWT_SECRET` | 开发占位 | JWT 签名密钥，**生产环境务必改成强随机串** |
| `PORT` | `3001` | 后端端口 |
| `CLIENT_URL` | `http://localhost:5173` | 允许的前端来源（CORS）；ngrok 等跨域场景设为 `*` |

## 项目结构

```
poker-app/
├── packages/shared/            # 前后端共享：类型、常量、事件协议
├── apps/server/
│   ├── src/game/               # ★ 纯游戏引擎（无网络/DB/定时器，可单测）
│   │   ├── deck.ts             #   牌组与洗牌（CSPRNG）
│   │   ├── hand-evaluator.ts   #   7 选 5 比牌 + 牌型描述
│   │   ├── pots.ts             #   主池 / 边池计算
│   │   ├── engine.ts           #   牌局状态机
│   │   └── __tests__/          #   单元测试
│   ├── src/table/              # 运行时牌桌（引擎 + 坐席 + Socket + 计时 + 落库）
│   ├── src/http/               # Fastify REST（名字入口/房间）+ 前端静态托管
│   ├── src/ws/                 # Socket.IO 网关（连接鉴权 + 事件分发）
│   ├── src/utils/              # JWT、限流
│   └── prisma/schema.prisma    # User / Room / Seat / Hand / HandAction
└── apps/web/                   # React 前端
    ├── src/pages/              # Landing / Login / Lobby / Table
    ├── src/components/         # 牌、座位、行动栏、聊天、结算弹窗等
    └── src/store/              # Zustand（auth 持久化、table 状态）
```

## 架构要点

- **引擎与网络/DB 解耦**：`src/game/` 是纯函数式状态机，所有方法同步返回事件数组（`handStarted` / `streetDealt` / `action` / `showdown` / `handEnded`），由外层 `Table` 负责广播、计时、落库。可脱离 UI 独立测试。
- **服务器权威 + 信息隔离**：完整状态只在服务端内存，推送给每个玩家的是「私有视图」（`TableView`），别人的底牌被抹掉，杜绝作弊。
- **自由带入筹码**：入座时决定带入多少虚拟筹码，无账户余额，与真实资金无关。

## 游戏规则（已实现）

- 盲注与按钮顺时针轮转，含**单挑（heads-up）特殊规则**：按钮即小盲、翻牌前按钮先行动
- 下注 / 过牌 / 跟注 / 加注 / 全下；**最小加注**规则，**短码全下（under-raise）不会重开加注**
- 发公共牌前**烧牌（burn）**；全部全下时自动发完剩余公共牌并摊牌
- **边池（side pot）**按各玩家投入金额正确分配
- 摊牌比牌：7 选 5，支持同花顺/四条/葫芦/同花/顺子/三条/两对/一对/高牌，含轮子顺子 A-2-3-4-5；牌型名称随玩家语言设置显示
- 下注轮次计数，动作文案区分 **raise / 3-bet / 4-bet**
- 快捷下注按钮（¼ / ½ / ¾ / 满池）+ 滑块

## 已知限制

- **单进程运行**：适合朋友规模（几十人、几张桌）。新版开始的手牌会在本机 `.runtime/room-state/` 保存私有恢复快照；服务重启后需房主恢复，不能把一桌同时运行在多台服务器。升级前未留下快照的手牌仍从上一手结算恢复。
- 大厅列表只显示当前进程内活跃的牌桌；每局结果虽已落库（`Hand` / `HandAction`），但暂未提供历史战绩回看界面。
- 名字入口限流为**内存版**（单进程有效），多实例部署时需换成共享存储。
